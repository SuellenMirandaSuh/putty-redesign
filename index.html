About PuTTY Signatures

We create GPG signatures for all PuTTY files distributed from our website, so that users can be confident that the files have not been tampered with. As of release 0.58, all PuTTY executables contain fingerprint material that can be accessed via the -pgpfp command-line option.

As of release 0.67, Windows executables and installers also contain built-in signatures that are automatically verified by Windows' own mechanism (Authenticode).

Security Details

Development Snapshots Key

The private key is stored without a passphrase because snapshots are generated nightly without human intervention.

Protects against:

  • • Tampering with binaries between website and you
  • • Web server maintainers tampering with binaries

Release Key

The private key is kept encrypted on developers' local machines, providing stronger security than the snapshot key.

Only used at release time to manually sign each release.

Master Key

The Master Key signs almost nothing. Its purpose is to bind all other keys together and certify that they are owned by the same people.

Especially long (4096-bit) with special security precautions for the private key and passphrase.
